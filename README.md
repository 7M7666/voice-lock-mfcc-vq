# 基于 MFCC 与 VQ 的多特征融合声音锁原型系统

本项目采用 MFCC 特征提取、VQ 声纹匹配与 DTW 口令模板匹配，实现注册用户的语音身份与口令验证。系统使用 Python + PySide6 构建一体化桌面应用，支持现场录音、用户注册和即时验证。

## 当前进度

- **系统功能**：已完成用户注册、录音验证、音频文件验证和用户管理，可展示波形、MFCC 特征、匹配分数及验证记录。
- **数据与实验**：已整理 99 条自采录音及标注，建立特征组合、码本大小、口令匹配和阈值校准的对比实验流程。
- **算法优化**：正在优化正常用户误拒和相近错误口令判别。多特征融合方案已完成一轮开发数据对照，待独立录音验证后确定是否接入应用。

## 下一阶段

- 补充独立测试录音，检验本人正确口令、本人错误口令及其他人冒充三类场景。
- 在实际演示设备上验证录音与操作稳定性，完善实验结果和结题展示材料。

目前已具备注册、建模、验证与结果展示的完整流程，识别稳定性和不同设备下的表现仍需进一步测试。
