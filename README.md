# Voice Lock · MFCC + VQ

基于 MFCC、LBG-VQ 与 DTW 的轻量化声音锁原型，采用 Python + PySide6 一体化桌面应用。

## 当前进度（2026-11-01）

### 已完成

- 支持本地用户注册、麦克风录音验证和 WAV 文件推理；注册需至少三条合格语音。
- 已接入注册质量提示、建模自检、波形与 MFCC 展示、分数与拒绝原因、验证记录及录音复核。
- 录音、建模和验证已移至后台，支持进度、电平提示及取消操作；支持删除用户时选择清理关联数据。
- 已具备 99 条自采 WAV、标注和离线实验流程，可进行特征、码本、DTW、阈值及融合对照。

### 算法与验证状态

- App 当前使用声纹与口令双门槛判定；口令分支比较声学模板，不识别文字。
- 最新“相对基频 + Delta”判定级融合候选已冻结，尚未部署。在 24 条校准 WAV 上，拟合与按 WAV 分组留一结果均为本人正确口令通过 **10/12**、负例误接受 **0/36**。这属于开发结果，尚未完成独立验收。
- 已有验证记录包括 71 项自动回归、GUI 冒烟和 3168 次冻结参数重放通过；真实设备表现仍待验收。

- 补充相近基频陌生人、跨设备和回放攻击测试，确认候选的适用范围。
