# 基于 MFCC 与 VQ 的多特征融合声音锁原型系统

SRDP 项目：在普通电脑和小样本自采录音条件下，使用 **MFCC、LBG-VQ 和 DTW** 实现用户注册、声音验证与实验结果展示。主程序是 Python + PySide6 桌面应用，适合课程展示、项目答辩和组内协作。

系统以“芝麻开门”为固定口令，通过声纹匹配和口令声学模板匹配共同判断是否接受。本项目是软件原型，未接入实体门锁。

## 快速开始

### 1. 准备环境

- Windows + PowerShell；以下命令均在项目根目录运行。
- Python **3.11**（本机验证版本为 3.11.9）和 Git。
- 现场注册、验证需要麦克风及系统录音权限；使用仓库 WAV 演示不需要麦克风。

### 2. 下载与安装

```powershell
git clone https://github.com/7M7666/voice-lock-mfcc-vq.git
cd voice-lock-mfcc-vq
python -m venv code/python/venv
.\code\python\venv\Scripts\python.exe -m pip install -r code/python/requirements.txt
```

仓库已包含基线模型、特征文件和 99 条正式录音，**首次演示无需重新训练**。依赖见 [requirements.txt](code/python/requirements.txt)，当前未锁定版本。

### 3. 启动应用

```powershell
.\code\python\venv\Scripts\python.exe code/python/gui.py
```

也可使用快捷入口：

```powershell
.\run.ps1 gui
```

若 PowerShell 阻止运行 `.ps1`，使用上面的 Python 直接启动命令即可。后续启动只需执行启动命令，不必重复安装。

### 4. 完成第一次验证

1. 首页点击“注册新用户”，输入用户名。
2. 每次点击录音后，等待“麦克风已启动”的提示，再完整说一遍“芝麻开门”。
3. 录满 **8 条合格语音**。不合格录音不计数；满 8 条后停止继续录制。选中样本后可点击“移除所选录音后重录”，再补录。
4. 点击“完成注册，去验证”，应用建立并保存用户模型，自动返回“声音验证”。
5. 确认当前用户，点击“开始录音验证”，重新说“芝麻开门”，查看通过/未通过和原因。

注册进度为 7/8 时不能完成注册，8/8 且填写用户名后才可完成。已有用户重启后可以直接选择验证；本次增加注册数量不会自动删除或重建旧用户模型。

## 演示与界面操作

### 使用已有录音展示

进入“项目实验 → 已有音频演示”，从“固定样例”选择音频，点击“开始验证”。此入口使用随仓库提供的基线模型，适合在没有麦克风时查看算法输出。

| 固定样例 | 用途 |
|---|---|
| 正常通过 S01 / S02 | 展示注册说话人的正常口令验证 |
| 错误口令拒绝 | 展示口令模板不匹配时的拒绝 |
| 非注册用户拒绝 | 展示陌生人录音的拒绝 |
| 边界样例 | 展示本人正常口令也可能被误拒的情况 |

“项目实验 → 算法对比结果”读取已有离线结果；点击刷新不会训练模型。这些结果与刚注册的现场用户验证分别展示。

### 使用现场用户模型

- **声音验证**：选择已注册用户并录音验证；展开“查看分数与录音特征”可查看分数、波形和 MFCC。
- **验证记录**：查看最近 20 条现场记录、导出记录或复核所选录音。已有音频演示不混入现场记录。
- **更新注册**：使用同名重新注册，完成时确认覆盖即可。
- **删除用户**：默认只删除用户模型，保留录音和历史；勾选关联数据清理时，按确认框列出的范围清理。
- **设置**：可测试麦克风、查看或加载模型。已有用户验证使用注册时保存的参数，切换基础模型不会自动更新旧用户模型。

录音和计算期间可点击“取消本次操作”；取消需要等待当前计算步骤结束。

## 方法与功能

```text
麦克风 / WAV
     ↓
语音质量检查与预处理
     ↓
特征提取与归一化
     ├─ MFCC + LBG-VQ：声纹匹配
     └─ 特征序列 + DTW：口令模板匹配
                    ↓
             接受 / 拒绝与分数
```

- **MFCC**：提取语音频谱特征，作为声纹与口令比较的输入。
- **LBG-VQ**：建立说话人码本，计算待测语音与用户模型的距离。
- **DTW**：对齐不同语速的特征序列，比较待测语音与注册口令模板的相似度。
- **注册质量检查**：给出静音、有效活动时长、近满幅和短促声音等提示，支持逐条移除与重录。
- **可追溯验证**：记录录音路径、模型指纹、距离/阈值及诊断信息，支持后续复核。
- **对比实验**：提供特征组合、码本大小、DTW 策略、阈值校准及融合方案的离线实验入口。

**口令分支比较声音相似度，不将语音识别成文字。** 因此，“口令模板匹配通过”不能直接解释为识别出了正确文字；该分数也会受到音色、语速和发音影响。

## 数据与实验结果

### 正式数据集

正式录音与标注位于 [data/demo_audio/](data/demo_audio/)，共 **99 条 WAV**，覆盖宿舍、走廊、实验室三种环境。

| 数据用途 | 数量 |
|---|---:|
| 注册说话人正确口令训练 | 36 |
| 注册说话人正常口令评估 | 24 |
| 错误口令评估 | 36 |
| 非注册用户评估 | 3 |
| 合计 | 99 |

标注表见 [metadata_srdp.csv](data/demo_audio/metadata_srdp.csv)。现场注册录音、用户档案和验证历史单独保存，不加入这 99 条正式数据。

### 仓库保留的历史基线

下表来自 [voice_lock_metrics.csv](results/tables/voice_lock_metrics.csv)，反映历史正式数据上的结果。

| 方案 / 评估类型 | 正确数 | 比例 |
|---|---:|---:|
| 单层 LBG-VQ：全部评估 | 52/63 | 82.5% |
| 声纹 + DTW 双层验证：全部评估 | 56/63 | 88.9% |
| 双层验证：正常用户通过 | 17/24 | 70.8% |
| 双层验证：错误口令拒绝 | 36/36 | 100.0% |
| 双层验证：非注册用户拒绝 | 3/3 | 100.0% |

这批评估数据已多次用于开发比较，不能作为新的独立泛化测试；3 条非注册用户样本也不足以证明广泛的陌生人拒识能力。历史离线成绩不代表现场新用户的表现。

### 当前版本与后续验证

- 应用保留原双门槛判定；新的融合候选已冻结，尚未部署，仍需独立录音与真实设备验收。
- 注册门槛已统一为 8 条合格录音，MFCC、VQ、DTW、阈值和正式基础模型未因本次改动而改变。增加样本不保证准确率提高，效果需通过新录音验证。
- 当前仍可能误拒本人正确口令；跨设备、相近声音陌生人、相近错误口令及回放攻击的验证仍需补充。
- 2026-10-29 已修复 LBG 训练实现；重新训练可能得到与历史表不同的结果。

详细实验依据、已知问题和后续验收计划见 [结题改造主线](docs/结题改造主线.md)。

## 组员开发与复现

### 基本检查

在项目根目录运行：

```powershell
# 模型推理、用户模型保存/加载与历史保存/加载检查，不使用麦克风
.\run.ps1 gui --smoke

# 检查正式数据和已有输出，不重新训练
.\run.ps1 smoke-test --skip-pipeline

# GUI 工作流回归，使用已有 WAV 模拟录音，覆盖 7 条不能注册、8 条可以注册
.\code\python\venv\Scripts\python.exe -m unittest discover -s code/python -p test_gui_workflow.py -v

# 全部自动测试
.\code\python\venv\Scripts\python.exe -m unittest discover -s code/python -p 'test_*.py' -v
```

自动检查不替代真实麦克风测试。现场演示前，使用实际答辩设备完成注册、本人正确口令、本人错误口令和其他人录音的检查，保留对应录音与结果。

### 命令行单条推理

```powershell
.\run.ps1 predict-one data/demo_audio/srdp_dataset/S01/corridor/S01_corridor_004.wav --expected-decision S01 --speaker-id S01 --split test
```

输出包含最终判定、预测说话人、声纹/口令分数、距离、阈值和拒绝原因。`--expected-decision` 用于核对预期结果，不指定算法必须输出什么。

### 离线实验入口

| 命令 | 实验内容 |
|---|---|
| `.\run.ps1 experiments` | 特征组合与码本大小对照 |
| `.\run.ps1 dtw-experiments` | DTW 模板聚合及对齐策略对照 |
| `.\run.ps1 fusion-experiments` | 融合权重、阈值与质量权重扫描 |
| `.\run.ps1 calibration-experiments` | 训练内留一与阈值校准对照 |
| `.\run.ps1 followup-experiments` | 路径、预处理、归一化与融合消融 |

实验会写入相应结果目录，具体参数可通过命令后的 `--help` 查看。现场候选分析和第二轮冻结验收依赖额外的本地录音、冻结参数及协议，输入条件见开发主线文档。

需要完整重新提取特征、训练并评估时才运行：

```powershell
.\run.ps1 pipeline --metadata data/demo_audio/metadata_srdp.csv
```

此命令会覆盖默认特征、基础模型及相应结果。运行前应保留要对照的模型和结果，比较时注明代码版本、数据范围与配置；它不是首次启动的必需步骤。
