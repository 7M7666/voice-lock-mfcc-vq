# SRDP 正式录音目录

正式采集的多人多场景 WAV 放在这里，目录建议按说话人和环境分层：

```text
S01/dorm/S01_dorm_001.wav
S01/corridor/S01_corridor_001.wav
S01/lab/S01_lab_001.wav
U01/corridor/U01_corridor_001.wav
```

本目录现有 99 条正式 WAV，标注以[metadata_srdp.csv](../metadata_srdp.csv)为准。早期 `docs/数据采集规范.md` 当前不存在；现行注册步骤见[项目 README](../../../README.md#四条注册与个人验证)。现场注册与验收录音保存在独立用户数据目录，不写入本目录。
