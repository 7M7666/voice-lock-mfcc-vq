# SRDP 声音锁 Windows 版

1. Windows 10/11 64 位：完整解压 ZIP，再双击 `SRDPVoiceLock.exe`。不需要 Python、MATLAB或管理员权限。
2. 请保留 EXE 旁边完整的 `_internal` 文件夹；不能只复制或下载一个 EXE。该版本未做代码签名，Windows 可能显示未知发布者，请核对 GitHub Release 来源及 SHA-256 后由你自行决定是否运行。
3. 首次使用在“注册用户”输入姓名，按提示录四条合格的“芝麻开门”，完成注册后选择该账号录音验证。固定样例在“项目实验”中，只是离线演示。
4. 麦克风须在 Windows 设置中允许桌面应用访问；首次特征计算需要加载依赖并建立缓存，请等待。真实设备验收仍须由使用者执行，程序自检使用 WAV 模拟输入，不证明认证准确率。

## 用户数据

用户数据保存在 `%LOCALAPPDATA%\SRDPVoiceLock`，与解压目录分开：

- `app_data/users/`：你注册的个人模型；`app_data/history.csv`：最近20条验证记录。
- `tmp/gui_recordings/`：你录制的原始 WAV；`app_data/diagnostics/`：注册质量记录和复核快照。
- `results/gui_history/`：导出的验证 CSV；`cache/`：运行缓存；`logs/startup.log`：启动日志。

关闭重开、移动解压目录或解压更新版本后仍使用同一 Windows 用户的数据。请勿把这个个人目录发给队友；删除用户默认只删除其模型，关联数据清理需在 App 中另行勾选确认。CSV 不包含音频，验收时应另存相应 WAV。发行 ZIP 不含开发者私人用户、现场录音和临时诊断数据，只保留仓库已有的九条演示/自检 WAV、基础模型、配套特征和必要离线表。

## 演示与测试边界

当前默认是 MFCC + VQ 与 MFCC + DTW 双门槛；DTW 比较声学模板，不识别文字。历史56/63属于自动选择说话人的离线协议，不能作为现场账号认证准确率。误拒和误通过均可能出现；本发行版只适合作为课程原型。

真实设备上请依次确认：注册、本人正确口令、本人相似错误口令、他人正确口令、他人错误口令、重启恢复、取消、静音及麦克风异常恢复。保留实际结果，不现场调参。

开发者可用 `SRDPVoiceLock.exe --self-test C:\可写目录\self-test.txt` 运行内置流程回归，结果写入指定文件，返回码0表示通过。它使用临时用户和模拟 WAV，不使用你的麦克风，不代表真实设备测试通过。遇到无法启动时保留 `logs/startup.log`；无需安装 Python 或重训模型来处理。
