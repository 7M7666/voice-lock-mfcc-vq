# 截至 5.20 的 SRDP 进度缺口清单

这里按申报书计划表的两个阶段来判断：`2026 年 1-3 月` 和 `2026 年 4-6 月`。因为 5.20 处在第二阶段中间，所以 4-6 月任务不一定全部完成，但至少要有阶段性证据。

## 2026 年 1-3 月计划

计划任务：

- 系统梳理基于 MFCC 与 VQ 的说话人识别方法；
- 阅读国内外相关文献，总结多特征融合与噪声鲁棒性进展；
- 在单人“声音锁”demo 和 MFCC 热力图基础上，规范录音口令、采样率等实验条件；
- 形成总体方案和详细技术路线；
- 明确功能模块划分与评测指标。

计划预期成果：

- 不少于 10 篇文献阅读笔记；
- 一份《项目总体设计与技术路线说明》；
- 整理并注释现有单人 demo 代码；
- 稳定复现语音波形与 MFCC 热力图；
- 为多用户扩展提供理论和实现基础。

### 当前已有证据

- 已有 Python 主程序：`code/python/srdp.py`，包含录音、SNR、特征提取、LBG-VQ 识别和拒识阈值。
- 已有单人录音样本：`data/demo_audio/enroll.wav`、`test.wav`、`my_voice.wav`。
- 已有单人模板：`models/template_single_user.npy`。
- 已有 MFCC 热力图：`results/figures/mfcc_single_user.png`。
- 已有语音预处理文档：`docs/语音预处理.docx`。
- 已有 MATLAB/Python 预处理代码，可支撑技术路线中的预处理模块。

### 1-3 月仍缺

- 缺“不少于 10 篇文献阅读笔记”的本地文件证据。
- 缺单独成文的《项目总体设计与技术路线说明》。
- 单人 demo 有代码，但还需要补充注释、运行说明和一张复现实验截图。
- 缺明确的评测指标文档，例如识别率、误识率、拒识率、混淆矩阵、SNR/环境标签。

## 2026 年 4-6 月计划

计划任务：

- 构建多场景语音数据集；
- 在宿舍、走廊、实验室等不同声学环境下完成数据采集；
- 进行信噪比或环境标签标注；
- 完善预处理与多维特征提取模块。

计划预期成果：

- 得到一套包含多场景环境噪声的数据集；
- 完成特征提取函数及 Z-score 归一化模块；
- 输出不同环境下的声学特征对比图谱。

### 当前已有证据

- 已有开放实验中的预处理函数：预加重、端点检测、分帧、短时能量、过零率。
- 已有多维特征提取 Live Script：MFCC、Delta MFCC、谱质心、谱带宽、谱能量、谱峰度、谱熵。
- 已有开放语料上的特征文件：`data/features/open_experiment_features.mat`。
- 已有开放实验的特征分析表：`results/tables/Feature_Analysis_Report.csv`。
- 已有 VAD 阈值扫描图，可说明对不同声学环境下预处理参数做过探索。
- 已有预处理示例图，可展示“原始波形-预加重-端点检测-能量/ZCR”的流程。
- 已补 Python 版批量特征提取与 Z-score 归一化：`code/python/srdp.py features`。
- 已补 Python 版近似 SNR 估算：`code/python/srdp.py snr`。
- 已补严格 LBG 分裂法 VQ 码本识别与拒识阈值实验：`code/python/srdp.py vq`。
- 已用单人 demo 音频跑通流程，生成 `results/tables/snr_estimates.csv`、`data/features/srdp_features.npz`、`results/tables/feature_summary.csv`、`results/tables/lbg_vq_recognition_results.csv` 和 `results/figures/lbg_vq_confusion_matrix.png`。

### 4-6 月截至 5.20 仍缺

- 缺 SRDP 自采的多人、多场景语音数据集。
- 缺自采数据的标注表。现在只有模板：`data/demo_audio/metadata_template.csv`。
- 缺宿舍、走廊、实验室等环境下的真实对比图谱。
- 缺基于自采数据输出的批量特征文件和特征统计结果；现有输出来自单人 demo 音频。
- Z-score 归一化代码已补，但还缺自采多环境数据上的归一化结果说明。
- 严格 LBG-VQ 码本训练与拒识阈值代码已补，但还缺多人数据上的有效识别/拒识实验。
- 缺真实多用户识别率、混淆矩阵、参数对比结果。
- 缺非注册用户/错误口令的拒识实验。

## 5.20 前最小补齐方案

1. 先补文档：建一个《项目总体设计与技术路线说明》，把 MFCC、VQ、预处理、特征融合、评测指标写清楚。
2. 整理文献：哪怕先做 10 条摘要式笔记，也要形成一个可交付文档。
3. 采集小数据集：至少 3 名说话人 x 3 个环境 x 每环境 5 条，共 45 条 WAV。
4. 填写 `metadata_template.csv`：说话人、环境、口令、采样率、训练/测试划分。
5. 用现有 MATLAB Live Script 或 Python 代码批量提取特征，并补 Z-score 归一化说明。
6. 输出三张答辩图：MFCC 热力图、预处理对比图、不同环境特征对比图。
7. 用严格 LBG-VQ 版本输出一张识别率/拒识率表和混淆矩阵。

## 答辩时可用表述

“截至 5.20，项目已完成单人声音锁 demo、语音预处理流程、MFCC 可视化、开放语料上的多维特征提取实验，并补齐了 Python 版批量特征提取、Z-score 归一化、严格 LBG-VQ 码本识别和拒识阈值流水线。当前主要差距在于自采多人多场景数据集，以及基于真实数据生成的环境对比图谱、识别率、拒识率和混淆矩阵。”
