# Python 代码缺口与推进说明

## 当前代码状态

现在 Python 端已收束为一个主程序：

- `code/python/srdp.py`

配套一个短命令入口：

- `run.ps1`

原来分散的录音、SNR、特征提取、VQ 训练、路径管理等脚本已经合并进 `srdp.py`，避免代码文件过多。

## 已补齐的代码主线

- 自采数据录音与 metadata 写入：`.\run.ps1 record ...`
- 近似 SNR 估算：`.\run.ps1 snr ...`
- MFCC、Delta MFCC、谱特征批量提取：`.\run.ps1 features ...`
- 基于训练集的 Z-score 归一化：集成在 `features` 子命令中。
- 严格 LBG 分裂法 VQ 码本训练：集成在 `vq` 子命令中。
- 拒识阈值实验：`vq` 子命令会输出 `decision=REJECT` 或注册说话人 ID。
- 一键流水线：`.\run.ps1 demo` 或 `.\run.ps1 pipeline --metadata data/demo_audio/metadata_srdp.csv`

## 当前已验证

已用现有单人 demo 音频跑通：

- `results/tables/snr_estimates.csv`

## 接下来真正缺的东西

1. 真实多人数据：至少 3 名说话人、3 个环境、每环境 5 条固定口令。
2. 未注册/错误口令样本：用于验证拒识阈值，不然“声音锁”的安全性讲不实。
3. 用真实数据重新跑 `pipeline`，生成真正可用于答辩的识别率、拒识率、混淆矩阵和环境对比图。
