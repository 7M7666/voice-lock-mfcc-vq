# SRDP 声音锁数据采集规范

## 结论

现在 `data/demo_audio` 里的 `enroll.wav`、`test.wav`、`my_voice.wav` 只是单人 demo 样本，只能证明流程能跑通，不适合作为中期答辩的正式数据。群内分享包不会放这些旧录音；正式实验请按下面规范重新采集。

## 固定设置

- 固定口令：`芝麻开门`
- 采样率：`16000 Hz`
- 声道：单声道
- 格式：WAV
- 单条时长：2.5-3.0 秒
- 录音距离：离麦克风约 15-30 cm
- 环境标签：
  - `dorm`：宿舍，相对安静
  - `corridor`：走廊，混响明显
  - `lab`：实验室或教室，有轻微背景噪声

## 最小数据量

中期答辩最低建议：

- 注册用户：至少 3 人，最好 5 人。
- 每名注册用户每个环境录 5 条固定口令。
- 每个环境的 5 条中，前 3 条作为训练集，后 2 条作为测试集。
- 最低数量：3 人 x 3 环境 x 5 条 = 45 条注册用户音频。

加分但很重要：

- 非注册用户：1-2 人，每人 3-5 条固定口令，预期结果填 `REJECT`。
- 错误口令：注册用户说 2-3 条错误口令，预期结果填 `REJECT`。

## 文件命名

统一放在：

```text
data/demo_audio/srdp_dataset/
```

命名示例：

```text
data/demo_audio/srdp_dataset/S01/dorm/S01_dorm_001.wav
data/demo_audio/srdp_dataset/S01/dorm/S01_dorm_002.wav
data/demo_audio/srdp_dataset/S01/corridor/S01_corridor_001.wav
data/demo_audio/srdp_dataset/S01/lab/S01_lab_001.wav
data/demo_audio/srdp_dataset/U01/corridor/U01_corridor_001.wav
data/demo_audio/srdp_dataset/S01_wrong/dorm/S01_wrong_001.wav
```

说话人编号：

- `S01`、`S02`、`S03`：注册用户。
- `U01`、`U02`：非注册用户。
- `S01_WRONG`：注册用户 S01 的错误口令样本。

## Metadata 表格

复制 `data/demo_audio/metadata_template.csv`，另存为：

```text
data/demo_audio/metadata_srdp.csv
```

字段含义：

```text
file_path,speaker_id,environment,passphrase,sample_rate_hz,duration_sec,split,expected_decision,notes
```

- `file_path`：相对项目根目录的音频路径。
- `speaker_id`：说话人编号。
- `environment`：`dorm` / `corridor` / `lab`。
- `passphrase`：口令。
- `sample_rate_hz`：16000。
- `duration_sec`：可空，程序会重新估算。
- `split`：`train` / `test` / `impostor` / `wrong_passphrase`。
- `expected_decision`：注册用户测试样本填 `S01` 这类编号；非注册或错误口令填 `REJECT`。
- `notes`：备注。

示例：

```csv
file_path,speaker_id,environment,passphrase,sample_rate_hz,duration_sec,split,expected_decision,notes
data/demo_audio/srdp_dataset/S01/dorm/S01_dorm_001.wav,S01,dorm,芝麻开门,16000,,train,S01,registered speaker train
data/demo_audio/srdp_dataset/S01/dorm/S01_dorm_004.wav,S01,dorm,芝麻开门,16000,,test,S01,registered speaker test
data/demo_audio/srdp_dataset/U01/corridor/U01_corridor_001.wav,U01,corridor,芝麻开门,16000,,impostor,REJECT,unregistered speaker
data/demo_audio/srdp_dataset/S01_wrong/dorm/S01_wrong_001.wav,S01_WRONG,dorm,错误口令,16000,,wrong_passphrase,REJECT,wrong passphrase
```

## 推荐录音命令

进入工程根目录：

```powershell
cd W:\LiWanlin\learnings\aricheive\lp\archive\srdp\04_项目工程
```

注册用户 S01 宿舍环境录 5 条，前 3 条训练，后 2 条测试：

```powershell
.\run.ps1 record --speaker S01 --environment dorm --takes 5 --train-count 3 --metadata metadata_srdp.csv
```

非注册用户录音，预期为拒识：

```powershell
.\run.ps1 record --speaker U01 --environment corridor --takes 3 --train-count 0 --expected-decision REJECT --metadata metadata_srdp.csv --notes impostor
```

错误口令录音，预期为拒识：

```powershell
.\run.ps1 record --speaker S01_WRONG --environment dorm --passphrase 错误口令 --takes 2 --train-count 0 --expected-decision REJECT --metadata metadata_srdp.csv --notes wrong_passphrase
```

采集完后跑完整实验：

```powershell
.\run.ps1 pipeline --metadata data/demo_audio/metadata_srdp.csv
```

## 质量检查

录完先检查：

```powershell
.\run.ps1 snr --metadata data/demo_audio/metadata_srdp.csv
```

建议重录的情况：

- 录音明显爆音或削波。
- 开头结尾空白太长。
- 时长小于 1 秒。
- 背景中有人声干扰、音乐、手机提示音。
- SNR 估算特别低，并且听感上已经影响口令。
