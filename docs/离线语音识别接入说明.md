# 个人验证的离线口令识别

在个人验证中，先运行原来的声纹和 DTW 判定。原判定通过后，离线识别同一条语音；转写按 NFKC 规范化、去除空白及标点符号后，必须严格等于“芝麻开门”才通过。原判定拒绝时不再识别。识别模型缺失、校验不符或运行失败时，界面显示验证失败，不回退成原算法的通过结果。语音识别文本及结果保存在本地验证历史中。旧历史记录和用户模型仍可加载；个人注册所需录音数量、质量准入、声纹模型和阈值均未改变。

新依赖为 `sherpa-onnx==2.0.1`。模型文件不放入 Git，也没有自动联网下载。需要事先从 `csukuangfj/sherpa-onnx-paraformer-zh-small-2024-03-09` 获取与以下哈希一致的文件：

- `model.int8.onnx`：`3ef6c19369b912f7caf3cef8e545c5ccd1a33d9d7ec792a46668dc41c4b229ec`
- `tokens.txt`：`4b2d964e18b9cf139b473003b6698fb2ed9a2a5ec55b93daa677b28f578897aa`

源码运行默认从项目目录的 `models/asr/` 读取，也可用环境变量 `VOICE_LOCK_ASR_DIR` 指向该目录。Windows 打包脚本现在要求在构建时提供模型文件，校验哈希后放入 `_internal/models/asr/`，打包运行默认从该位置读取；也可通过环境变量覆盖。模型的整个上游包与配套文件再分发授权尚需核实，不能把它随发行版发布为已经完成许可确认。启动过程中无需联网。

此分支仅修改源码，未合并 master、未重新打包。自动识别的历史实验演示仍走既有 `predict_one`，不要把其历史结果当作新版个人验证成绩。25 条手机录音的配对对照为了探索而绕过质量准入，不能表明正式注册成功；没有冒充测试，也没有 Windows 真机验证。具体表现和设备兼容性仍需独立录音验收。
