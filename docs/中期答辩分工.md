# SRDP 中期答辩分工建议

## 技术路线取舍

中期答辩阶段建议以 Python 为主线推进。

理由：

- Python 端已经有完整流水线：录音、metadata、SNR 估算、MFCC/Delta/谱特征、Z-score、严格 LBG-VQ、拒识阈值、结果表和混淆矩阵。
- 5.20 最缺的是自采数据和实验结果，不是再做一套 MATLAB 主流程。
- MATLAB 仍可保留为展示/交叉验证/GUI 加分项，但不建议在中期前继续扩展成第二条主线，否则会分散时间。

结论：

- 必做：Python 实验结果。
- 选做：MATLAB GUI 截图或流程演示。
- 不建议：Python 和 MATLAB 同时各做一套完整识别系统。
